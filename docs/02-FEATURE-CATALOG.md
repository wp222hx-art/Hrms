## 模块 1：多租户与组织管理

### 1.1 已实现功能

| 功能点 | 描述 | 业务价值 |
|---|---|---|
| **多租户隔离** | 每个客户独立数据空间，HR 仅可见所属租户 | 一个 SaaS 实例服务多家企业 |
| **租户 CRUD** | 超级管理员创建/编辑/删除租户 | 平台运营商可独立管理客户 |

| **数据驻留切换** | 按租户区域决定货币/时区/合规方案 | 跨境企业一站式 |

## 模块 6：薪资核算（核心差异化）

### 6.1 已实现功能

#### 6.1.1 一键发薪
| 功能点 | 描述 |
|---|---|
| **月份选择** | 任意年月可发薪 |
| **运行按钮** | 加载动画 + 一次完成全员计算 |
| **4 KPI 汇总** | Gross / Statutory / Tax / Net |
| **明细列表** | 每员工一行：工号 / 姓名 / 部门 / 数额 |
| **CSV 导出** | 按行政部门要求格式 |

#### 6.1.2 三地法定缴款引擎

**新加坡 (SG)**：
- CPF (Central Provident Fund)：
  - 雇员 20%（55 岁以下）
  - 雇主 17%
- SDL (Skills Development Levy)：0.25%
- IRAS 累进个税：0% / 2% / 3.5% / 7% / 11.5% / 15% / 18% / 19% / 19.5% / 20% / 22% / 23% / 24%

**中国 (CN)**：
- 养老保险：雇员 8% / 雇主 16%
- 医疗保险：雇员 2% / 雇主 9.5%
- 失业保险：雇员 0.5% / 雇主 0.5%
- 工伤保险：雇主 0.5%（雇员免缴）
- 生育保险：合并到医疗（雇主侧）
- 住房公积金：雇员 7% / 雇主 7%
- 个税：5000 元起征点 + 7 级累进税率（3%–45%）

**马来西亚 (MY)**：
- EPF (Employees Provident Fund)：雇员 11% / 雇主 13%
- SOCSO (Social Security)：雇员 0.5% / 雇主 1.75%
- EIS (Employment Insurance Scheme)：双边各 0.2%
- LHDN PCB 累进个税

#### 6.1.3 工资条 Payslip

- **收入项**：基本工资 + 加项
- **雇员扣款**：法定缴款 + 个税
- **雇主缴款明细**：单独展示企业成本
- **实发净额**：突出显示
- **可打印 PDF**：浏览器原生打印（A4 优化排版）

### 6.2 演进规划

- ☐ **更多薪资项**：加班费 / 绩效奖金 / 提成 / 津贴 / 餐补 / 房补 / 交通补贴
- ☐ **薪酬等级管理**：职级 → 薪酬带宽
- ☐ **调薪审批流**：申请 → 审批 → 历史记录
- ☐ **多次发薪**：月薪/周薪/双周薪
- ☐ **年终奖单独计税**（CN）
- ☐ **银行批量发薪**：生成银行代发文件
- ☐ **个税申报对接**：CN 自然人电子税务局 / SG IRAS API / MY LHDN
- ☐ **薪资 BI**：人力成本占比 / 部门薪酬对比 / 同行业 benchmark
- ☐ **保密薪酬**：HR 内部分级访问控制
