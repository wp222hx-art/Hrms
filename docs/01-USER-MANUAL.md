## 2. 系统概览

### 2.1 产品定位

**HRMS Cloud** 是一款面向中小企业（10–500 人）的多租户 SaaS 人力资源管理系统，提供从员工档案到薪酬合规的全流程闭环管理，支持新加坡 / 中国 / 马来西亚三地不同法定要求。

### 2.2 系统架构（用户视角）

```
┌─────────────────────────────────────────────────────────┐
│   登录页 (角色选择)                                       │
└─────────────────────────────────────────────────────────┘
              ▼
┌─────────────────────────────────────────────────────────┐
│   AppShell (顶栏 + 侧栏/抽屉 + 底部 Tab 栏)               │
│   ┌─────────────────────────────────────────────────┐   │
│   │ 仪表盘 │ 员工 │ 考勤 │ 请假 │ 报销 │ 薪资 │自助 │ 管理后台│
│   └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 2.3 八大核心模块

| 序号 | 模块 | 主要功能 | 适用角色 |
|---|---|---|---|
| ① | **仪表盘** | KPI 统计 / 趋势图 / 待办 / 快捷入口 | 全员（视角不同） |
| ② | **员工管理** | 档案 CRUD / 部门筛选 / 详情 Tab | HR / 经理 |
| ③ | **考勤管理** | 实时打卡 / 出勤统计 / 历史记录 | 全员 |
| ④ | **请假管理** | 申请 / 审批 / 余额查询 | 全员 |
| ⑤ | **报销管理** | 提交 / 审批 / 标记已支付 | 全员 |
| ⑥ | **薪资管理** | 一键发薪 / 法定缴款 / 工资条 | HR |
| ⑦ | **员工自助** | 我的资料 / 隐私同意 / DSAR 申请 | 全员 |
| ⑧ | **管理后台** | 租户 CRUD / 平台运营 / 数据重置 | 超级管理员 |

## 6. 模块详细操作

### 6.1 仪表盘 Dashboard

**入口**：登录后默认进入；侧栏第一项；底部 Tab 第一项。

**显示内容**：
- **5 个 KPI 卡片**：员工总数 / 今日出勤 / 今日缺勤 / 待审请假 / 待审报销
- **出勤趋势图**：近 10 个工作日 SVG 折线图
- **部门分布甜甜圈图**：按部门人数比例
- **待办队列**：未审批的请假和报销，点击直达详情
- **快捷操作**：根据角色显示不同按钮（新增员工 / 申请请假 / 提交报销 / 运行薪资）

### 6.2 员工管理

#### 6.2.1 员工列表

- **搜索**：按姓名 / 工号 / 邮箱实时筛选
- **筛选**：按部门下拉选择
- **新增**：右上角"新增员工"按钮 → 弹窗表单

#### 6.2.2 员工详情

点击列表中"查看"进入，包含 4 个 Tab：
- **概览**：个人信息 + 雇佣信息 + 请假余额（年假/病假/事假 3 块卡片）
- **考勤**：该员工最近 30 天考勤记录
- **请假**：该员工所有请假记录
- **工资条**：该员工历史工资条

#### 6.2.3 新增员工

填写字段（按区域自动验证）：
- 个人信息：姓名 / 邮箱 / 电话 / 工号
- 雇佣信息：部门 / 职位 / 雇佣类型（全职/兼职/合同/实习）/ 入职日期
- 薪酬：月度基本工资（按租户币种）

### 6.3 考勤管理

#### 6.3.1 打卡（员工视角）

```
┌────────────────────────────┐
│ 2026-05-30                  │
│ 09:15:23                    │  ← 实时时钟（每秒刷新）
│ 班次：09:00 — 18:00        │
│                             │
│      [👆 上班打卡]          │
└────────────────────────────┘
```

- 9:05 之前打卡 → 状态 `PRESENT`（正常出勤）
- 9:05 之后打卡 → 状态 `LATE`（迟到）
- 已打卡后按钮变为"下班打卡"
- 全部完成后按钮变为禁用"已完成"

#### 6.3.2 HR/经理视角

额外显示：
- **今日出勤汇总 4 KPI**：在岗 / 迟到 / 缺勤 / 休假
- **全员考勤列表**：可看到所有员工的考勤记录

### 6.4 请假管理

#### 6.4.1 申请请假

1. 点击"申请请假"
2. 选择类型（年假 / 病假 / 事假）
3. 选择起止日期（自动计算天数）
4. 填写原因
5. 提交 → 状态变为"待审"

#### 6.4.2 审批（HR/经理）

- 列表中"待审"状态的请假后会出现 `[批准] [拒绝]` 按钮
- 点击后弹出确认对话框
- 批准后状态变为 `approved`，员工可在工资条计算时看到影响

#### 6.4.3 余额卡片

页面顶部显示 3 张卡片：
```
[ 年假 14 ]   [ 病假 14 ]   [ 事假 3 ]
```

### 6.5 报销管理

#### 6.5.1 提交报销

1. 点击"新建报销"
2. 选择类别（差旅 / 餐饮 / 办公用品 / 培训 / 软件 / 客户招待）
3. 输入金额 + 币种
4. 填写描述
5. （演示模式下）票据上传按钮禁用
6. 提交 → 状态 `submitted`

#### 6.5.2 审批流转

```
submitted (已提交)
   ↓ [批准]
approved (已批准)
   ↓ [标记已支付]
paid (已付款)

submitted
   ↓ [拒绝]
rejected (已拒绝)
```

### 6.6 薪资管理

#### 6.6.1 运行薪资（HR 专属）

1. 选择月份（如 `2026-05`）
2. 点击"运行薪资"按钮（按钮显示加载动画约 400ms）
3. 自动调用区域薪资引擎：
   - **SG**：CPF 雇员 20% + 雇主 17% + SDL 0.25%
   - **CN**：养老 8% + 医疗 2% + 失业 0.5% + 公积金 7%
   - **MY**：EPF 雇员 11% + 雇主 13% + SOCSO + EIS
4. 自动计算个税（按当地累进税率）
5. 列表显示每个员工的：Gross / Statutory / Tax / **Net**

#### 6.6.2 工资条

点击列表行 → 弹窗显示完整工资条：
- 收入项（Earnings）
- 雇员扣款（Statutory + Tax）
- 雇主缴款（Employer Contributions，企业成本）
- **实发金额（Net Pay）**

点击"下载 / 打印"→ 浏览器原生打印对话框 → 可另存为 PDF。

#### 6.6.3 导出 CSV

按钮"导出 CSV"→ 自动下载文件名格式 `payroll-{tenantId}-{month}.csv`，可用 Excel 打开。

### 6.7 员工自助 Self-Service

#### 6.7.1 我的资料

- 头像 + 姓名 + 部门 + 职位
- 邮箱 / 电话 / 入职日期 / 月薪（只读，需 HR 修改）

#### 6.7.2 隐私与同意管理（PDPA / GDPR）

- 三个 Toggle：营销同意 / 分析同意 / 薪酬数据处理同意
- 同意状态实时显示绿色对勾

#### 6.7.3 数据主体权利申请（DSAR）

四种申请类型：
- **Access** 查看我的数据
- **Correct** 修正我的数据
- **Delete** 删除我的数据
- **Export** 导出我的数据

提交后生成参考号 `DSAR-XXXXXX`（30 天内响应）。

### 6.8 管理后台 Admin Console

**仅超级管理员可见**。

#### 6.8.1 平台运营 KPI（4 个）

- 租户总数
- 用户总数（所有租户员工合计）
- 活跃租户数
- 试用中租户数

#### 6.8.2 租户管理

- **新建租户**：填写名称（中英）/ 区域 / 套餐 / 席位数 / 状态 / 主题色
  - 区域改变时自动联动币种（SG→SGD / CN→CNY / MY→MYR）和合规方案
- **编辑租户**：随时调整套餐、席位、状态（活跃 / 试用 / 暂停 / 过期）
- **删除租户**：连同该租户所有员工数据一并删除
- **重置 Demo 数据**：一键还原所有租户至出厂状态（不可撤销）

## 7. 多租户与多区域

### 7.1 数据隔离

- 每个租户的员工、考勤、请假、报销、薪资完全独立
- HR 仅能看到所属租户的数据
- 超级管理员可在 Admin Console 跨租户管理

### 7.2 区域差异

| 维度 | 新加坡 (SG) | 中国 (CN) | 马来西亚 (MY) |
|---|---|---|---|
| 货币 | SGD | CNY | MYR |
| 时区 | Asia/Singapore | Asia/Shanghai | Asia/Kuala_Lumpur |
| 法定缴款 | CPF + SDL | 五险一金 | EPF + SOCSO + EIS |
| 个税口径 | IRAS 累进 | 国税局累进 + 起征点 | LHDN |
| 默认部门翻译 | 英文 | 中文 | 英文 |

### 7.3 切换租户

顶栏左侧租户名称 → 下拉 → 选择目标租户 → 整个工作区切换。

## 10. 常见问题 FAQ

### Q1：Demo 数据会被覆盖吗？
**A**：每个浏览器独立保存（localStorage），不会相互干扰。可在 Admin Console 一键重置。

### Q2：为什么切换租户后表格没刷新？
**A**：当前版本部分模块需要手动刷新页面。生产版本将自动监听租户切换。

### Q3：移动端的打卡和桌面端一致吗？
**A**：完全一致。所有功能在移动端都能正常使用。

### Q4：能上传真实的报销凭证吗？
**A**：Demo 版禁用了文件上传。生产版支持 PDF / JPG / PNG，上限单文件 10MB。

### Q5：工资条可以邮件发送吗？
**A**：Demo 版仅支持浏览器打印。生产版支持邮件自动发送 + 数字签名。

### Q6：支持 SSO 单点登录吗？
**A**：Demo 版无密码登录。生产版支持 SAML 2.0 / OIDC / Microsoft Entra ID / Google Workspace。

### Q7：能对接钉钉 / 企业微信吗？
**A**：路线图已规划，包括打卡同步、消息推送、组织架构同步。

### Q8：薪资税务计算的依据？
**A**：基于截至 2026 年的：
- 新加坡：IRAS 累进税表 + CPF Ordinary Wages Ceiling
- 中国：个税法（起征点 5000/月）+ 国务院五险一金条例
- 马来西亚：LHDN PCB Schedule

请咨询当地税务师定期核对。
