## 🎯 三分钟速读

### 这是什么？
面向 **中小企业（10–5000 人）** 的多租户 SaaS HR 系统，亚太聚焦（**新加坡 / 中国 / 马来西亚** 三地合规开箱即用），覆盖 **员工档案 / 考勤 / 请假 / 报销 / 薪资 / 自助 / 管理后台** 8 大模块，**双语 + 移动响应式**。

### 适合谁？
- ✅ **中小企业 HR**：替代 Excel + 钉钉审批，月节省 20+ 工时
- ✅ **跨境企业**：一套系统同时管理 SG / CN / MY 员工
- ✅ **创业团队 / SI 集成商**：可白标二次售卖，源码买断价 ¥150–500 万
- ✅ **产品经理 / 投资人**：体验现代化 HR SaaS 的完整形态

### 一句话定位
> **"像 Workday 一样专业，像钉钉一样易用，像 BambooHR 一样美观，价格只要 1/10。"**
